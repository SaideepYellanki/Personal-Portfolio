## 🛠️ Local Setup & Run Instructions

No complex build tools or dependencies are required. You can run it directly in any browser:

1. **Clone or Download this Repository**:
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/saideep-portfolio.git
   cd saideep-portfolio
   ```

2. **Open `index.html`**:
   - Double-click `index.html` to view in your browser.
   - OR run a lightweight local server:
     ```bash
     # Using Python
     python -m http.server 8080

     # Using Node npx serve
     npx serve .
     ```
   - Open `http://localhost:8080` in your browser.

```bash

```

### Step 3: Create a New Repository on GitHub
1. Go to [GitHub](https://github.com/new).
2. Set Repository Name: `saideep-portfolio` (or `portfolio`).
3. Set Visibility: **Public**.
4. Click **Create repository** (do not initialize with README, as we already created one).

### Step 4: Link Remote & Push to GitHub
Copy your repository URL from GitHub and run:
```bash
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/saideep-portfolio.git
git push -u origin main
```

4. Click **Save**.
5. Within 1-2 minutes, your live site will be available at:
